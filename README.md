# CraftBook

O CraftBook é uma aplicação web para ajudar jogadores de Minecraft a planejar
construções e farms. Ela reúne um catálogo de materiais e calcula os recursos
necessários para cada projeto.

## O que o projeto faz

- Permite buscar e filtrar materiais por categoria.
- Monta uma lista de materiais para a construção planejada.
- Calcula as quantidades necessárias e expande receitas de criação.
- Considera quantos itens o jogador já tem no inventário e mostra o que ainda falta.
- Permite selecionar a edição Java ou Bedrock e a quantidade de construções.
- Apresenta os materiais com imagens para facilitar a identificação.
